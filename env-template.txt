# Instructions:
# 1. Create a file named ".env" in your frontend root directory
# 2. Copy the contents above into the .env file
# 3. Modify the values according to your environment:
#    - VITE_API_BASE_URL: Your API server URL
#    - VITE_API_SCHEMA: Protocol (http or https)
#    - VITE_API_HOST: Your domain or IP address
#    - VITE_API_PORT: Port number (443 for https, 80 for http, or custom)
#    - VITE_PROJECT_FOLDER: Subfolder path if not in root
# 4. Upload both the .env file and the updated source files to your hosting provider
# 5. Your application will load with the configured settings
